# Mercy Barasa & Co. Advocates — Cecilia Mwaura template replica

This project is built directly from the Cecilia Mwaura & Co. Advocates template source and preserves its layout, component structure, spacing, responsive breakpoints, contact rail, footer, hero, practice cards, profile section, image band, CTA bands and page architecture. Only Mercy Barasa branding, copy, contact information and supplied assets have been adapted.

## Check
`npm run check`

## Build
`npm run build`

## Preview
`npm run dev`

## Deploy
`vercel --prod --yes`

The Google Map is only on the Contact page.
